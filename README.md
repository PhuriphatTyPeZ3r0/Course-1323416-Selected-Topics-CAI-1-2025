## 💻 4. แบบฝึกหัดและการทดลองภาคปฏิบัติ (Labs & Assignments)

| ลำดับโมดูล | หัวข้อการทดลอง (Hands-on Labs) | สาระสำคัญและเนื้อหาการปฏิบัติ | โฟลเดอร์ซอร์สโค้ด |
| :---: | :--- | :--- | :---: |
| **Module 01** | Web Environment & Architecture | โครงสร้างโปรโตคอล HTTP, การตั้งค่าสภาพแวดล้อมนักพัฒนาเว็บ | [เปิดโค้ด](02_Labs_Assignments/01-Introduction/) |
| **Module 02** | HTML5 Semantic Web Structure | ออกแบบโครงสร้างเว็บเพจ, ตาราง, และแบบฟอร์มรับข้อมูล (Forms) | [เปิดโค้ด](02_Labs_Assignments/02-HTML/) |
| **Module 03** | Advanced CSS3 Layout & Styling | ออกแบบหน้าเว็บด้วย Box Model, Positioning, Flexbox, Responsive Design | [เปิดโค้ด](02_Labs_Assignments/03-CSS/) |
| **Module 04** | Bootstrap 5 Responsive Layouts | พัฒนาหน้าเว็บ Responsive ด้วย Grid System, Navbars, Modals, Cards | [เปิดโค้ด](02_Labs_Assignments/04-Bootstrap/) |
| **Module 05** | DOM Manipulation with Pure JavaScript | จัดการโครงสร้าง HTML แบบไดนามิก, Interactive Event Listeners | [เปิดโค้ด](02_Labs_Assignments/07-DOM/) |
| **Module 06** | jQuery Library Integration | การค้นหาและควบคุม Selectors, Animation, Event Binding ด่วน | [เปิดโค้ด](02_Labs_Assignments/08-jQuery/) |
| **Module 07** | Node.js Runtime & Express Server | ติดตั้งโมดูล NPM, รันเว็บเซิร์ฟเวอร์ Express.js, Basic HTTP Routing | [เปิดโค้ด](02_Labs_Assignments/BE1-NodeJS/) |
| **Module 08** | Express Middleware & Routing Logic | การใช้งาน Body-parser, กำหนด Custom Middleware, จัดการ Route Handlers | [เปิดโค้ด](02_Labs_Assignments/BE1-NodeJS-2/) |
| **Module 09** | RESTful API Integration & Fetching | ดึงข้อมูลจากภายนอกผ่าน HTTP APIs, JSON Parsing, Postman Testing | [เปิดโค้ด](02_Labs_Assignments/BE3-API/) |
| **Module 10** | EJS Templating & Dynamic Web Pages | Render ข้อมูลลงในเทมเพลต EJS, สร้าง CRUD Web Applications | [เปิดโค้ด](02_Labs_Assignments/BE6-EJS/) |
